MJSMonitor package repositories

dnf (RHEL, AlmaLinux, Rocky, Fedora)

  • MJSMonitor 1.1.3 (el10, 64-bit ARM)
  • MJSMonitor 1.1.3 (el10, 64-bit Intel/AMD)

Add the repository once, then MJSMonitor updates with the rest of the system:

sudo rpm --import https://msanty573.github.io/MJSMonitor-Downloads/RPM-GPG-KEY-mjsmonitor
sudo curl -o /etc/yum.repos.d/mjsmonitor.repo https://msanty573.github.io/MJSMonitor-Downloads/mjsmonitor.repo
sudo dnf install mjsmonitor

apt (Ubuntu 26.04 and newer)

  • MJSMonitor 1.1.3 (64-bit Intel/AMD)
  • MJSMonitor 1.1.3 (64-bit ARM)

Installing the package also adds this repository, so MJSMonitor then updates with the rest of the system:

wget https://github.com/msanty573/MJSMonitor-Downloads/releases/download/latest/mjsmonitor.ubuntu.$(dpkg --print-architecture).deb
sudo apt install ./mjsmonitor.ubuntu.*.deb
